## Deploy free with GitHub Pages

1. Create a GitHub account at github.com if you don't have one
2. Create a new repository named exactly: `yourusername.github.io`
3. Make it public, then upload ALL files and folders from this folder (preserve structure)
4. Go to Settings → Pages → Source: "Deploy from a branch" → main → /(root) → Save
5. Wait 1–2 minutes — your site is live at `https://yourusername.github.io`

## Deploy free with Netlify (easier)

1. Go to netlify.com and sign up
2. Drag this entire `judah-portfolio` folder onto the deploy area
3. Site is live instantly with a Netlify URL

## Adding new articles later

2. Open `index.html`, find the writing section, and copy one of the existing article cards
3. Update the link, category, date, title, and excerpt
